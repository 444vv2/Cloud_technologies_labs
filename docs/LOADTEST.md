# Навантажувальне тестування

Інструмент: k6. Сценарій: `loadtest/k6.js`.

```
k6 run -e BASE_URL=http://<alb-dns> -e EMAIL=... -e PASSWORD=... -e VUS=40 loadtest/k6.js
```

Профіль: на ітерацію 1×`POST /songs` + 9 читань (`GET /songs`, `GET /songs/:id`, `GET /artists/:id`). Фази: 0→N за 2,5 хв, N 5 хв, N→0 за 2 хв. N (`VUS`) підібрано = 40.

## Результати (кеш вимкнено)

| Запитів | Частка помилок     | p50    | p95    | p99    |
| ------- | ------------------ | ------ | ------ | ------ |
| 19 382  | 0,03% (6 з 19 382) | 398 мс | 2,11 с | 3,01 с |

Додатково: середня латентність 635 мс, 33,9 запиту/с, 1938 ітерацій, 2,5 ГБ отриманих даних. Поріг `p(95)<500ms` не виконано, що пояснюється `GET /songs` без пагінації: база виросла з ≈30 до ≈2000 пісень за час тесту.
